## 주요 내용 및 키워드 정리

### 1. 클래스 개념 및 캡슐화 (Class Concept & Encapsulation)

- **캡슐화 (Encapsulation):** 객체의 내부 구현인 'HOW'(Body)는 숨기고, 외부에 제공하는 서비스인 'WHAT'(Public Interface)만을 노출하는 개념입니다.
- **기본 생성자 (Default Constructor):** 인자가 없는 생성자로, 클래스 내에 생성자가 정의되지 않은 경우 시스템이 자동으로 제공합니다. 단, C++의 경우 다른 생성자가 존재하면 자동으로 생성되지 않아 배열 선언 시 오류가 발생할 수 있습니다.

### 2. 상속 (Inheritance)

- **코드 재사용:** 기존 클래스(Base/Super Class)의 정보를 재사용하여 새로운 클래스(Derived/Sub Class)를 생성하는 강력한 메커니즘입니다.
- **계층 구조:** 부모 클래스의 멤버를 상속받으며, 필요에 따라 새로운 멤버를 추가하거나 상속받은 함수를 수정할 수 있습니다.
- **객체 생성 과정:** 서브 클래스 생성 시 슈퍼 클래스의 데이터 멤버 정보를 먼저 파악한 후, 서브 클래스의 생성자에서 `super()`를 호출하여 부모 객체를 먼저 초기화합니다.

### 3. 오버라이딩 (Overriding)

상속받은 메서드를 서브 클래스의 목적에 맞게 재정의하는 것으로, 주요 사용 목적은 다음과 같습니다.

- **확장 (Extension):** 상속받은 동작에 서브 클래스만의 추가적인 행위를 더함.
- **적응 (Adaptation):** 슈퍼 클래스의 동작을 서브 클래스의 특성에 맞게 구체화함.
- **최적화 (Optimization):** 특정 클래스에 더 효율적인 알고리즘으로 성능을 개선함.

### 4. 다형성 및 동적 바인딩 (Polymorphism & Dynamic Binding)

- **형 변환 (Type Conversion):** 서브 클래스는 슈퍼 클래스의 위치를 대체할 수 있지만(Upcasting), 슈퍼 클래스는 서브 클래스의 위치를 대체할 수 없습니다.
- **동적 바인딩 (Dynamic Binding):** 실행 시간(Runtime)에 객체의 실제 타입에 따라 적절한 오버라이딩 함수가 선택되어 호출되는 원리입니다.
- **다형성의 활용:** 서로 다른 서브 클래스 객체들을 하나의 슈퍼 클래스 타입 배열로 관리하며 동일한 인터페이스(메서드 호출)를 통해 각기 다른 동작을 수행하게 할 수 있습니다.

### 5. 추상 클래스와 인터페이스 (Abstract Class & Interface)

#### 추상 클래스 (Abstract Class)

- 하나 이상의 추상 메서드(구현이 없는 메서드)를 포함하는 클래스입니다.
- 직접 객체를 생성할 수 없으며, 서브 클래스에서 모든 추상 메서드를 구현해야 객체 생성이 가능합니다.

#### 인터페이스 (Interface)

- 모든 메서드가 추상 메서드인 '극단적인 형태의 추상 클래스'입니다.
- **특징:** 메서드는 암시적으로 `public abstract`이며, 필드는 `public static final`입니다.
- **다중 구현:** 자바는 단일 상속만 지원하지만, 인터페이스는 한 클래스가 여러 개를 동시에 구현(implements)할 수 있습니다.
- **느슨한 결합 (Weak Coupling):** 컴포넌트 간의 직접적인 의존성을 줄여 통신 구조를 유연하게 만드는 데 사용됩니다.

### 키워드 정리

- **Encapsulation:** 정보 은닉 (Public Interface vs. Hidden Body)
- **Inheritance:** 코드 재사용, Super/Sub Class 관계
- **Overriding:** 메서드 재정의 (Extension, Adaptation, Optimization)
- **Polymorphism:** 다형성, 업캐스팅(Upcasting), 동적 바인딩
- **Abstract Class:** 추상 메서드, 미완성 설계도
- **Interface:** 규격/약속, 다중 구현, 느슨한 결합(Loose Coupling)
